# Fire particle model

Gazebo Harmonic model using the built-in `gz::sim::systems::ParticleEmitter` system. It emits an upright, textured flame sprite with a changing orange/yellow life color and upward velocity. The effect is animated in simulation and intended for RGB-camera rendering. It does not simulate heat, combustion, or fire interaction.

Textures in `materials/textures/` were generated specifically for this project; no external mesh or downloaded model is used.
