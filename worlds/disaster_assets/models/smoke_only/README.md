# Smoke particle model

Gazebo Harmonic model using the built-in `gz::sim::systems::ParticleEmitter` system. It emits soft, textured grey particles upward; particles expand and fade over their lifetime. Intended for RGB-camera rendering. It does not simulate fluid dynamics or physical smoke interaction.

Textures in `materials/textures/` were generated specifically for this project; no external mesh or downloaded model is used.
